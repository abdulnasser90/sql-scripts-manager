# SQL Scripts Manager v2.0

نظام متكامل لإدارة ومزامنة سكريبتات SQL بقاعدة بيانات SQLite وواجهة ويب حديثة.

## الميزات
- قاعدة بيانات SQLite مدمجة ومستقلة (`scripts.db`).
- تصنيف وتقسيم السكريبتات حسب الأقسام (Views, Queries, DBMS, DDL, ...).
- إضافة وتعديل وحذف السكريبتات مع محرر كود وتفضيل.
- بحث فوري بالاسم والوصف ومحتوى كود SQL.
- نسخ فوري متوافق مع Localhost والشبكات المحلية.

## التشغيل المحلي
```bash
node server.js
```
ثم افتح المتصفح على `http://localhost:3000`.
